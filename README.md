# Learning Lab 001

Aqsa Umar’s 28-day independent project explores whether AI-assisted questioning helps her recall and apply what she learns. It includes a daily roadmap, a storyboard journal and the manual ExplainBack prototype.

## Start here

Extract the ZIP and open index.html in a modern browser. Use the same browser and URL each day so your notes stay together. For consistent storage, use the GitHub Pages URL once published, or serve this folder locally with `python -m http.server 8000` and open `http://localhost:8000`. Export your journal before changing URLs or browser profiles.

On Day 01, read the retrieval practice material, write your 150–200 words from memory, and choose three concepts. Run the immediate test on Day 02 and repeat it on Day 04, at least 48 hours later. The five-day companion worksheet has the prompts, scores table and storyboard template. The site records your checks and evidence. Its checks are self-assessments, and reminders appear while using the site.

When upgrading at the same URL, related notes from the original first week carry forward and the revised lessons start unchecked. Later lessons retain their progress. The original browser record remains available to the previous version.

## Publish on GitHub Pages

1. Sign in to GitHub and create a public repository named learning-lab-001.
2. Upload the files in this folder to the root of the repository’s main branch. Upload the files, not the enclosing folder or the ZIP.
3. In Settings → Pages, choose Deploy from a branch, then select main and / (root). Save.
4. Open the URL shown in Settings → Pages. Verify Day 01, the incomplete-day dialog and ExplainBack with a fictional session.

The public files contain the curriculum and the prototype. Personal journals and ExplainBack sessions live in local browser storage. The AI exercises use separate public or local tools. No server or API key is required for the website.
