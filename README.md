# Learning Lab 001
live at : http://aqsabrohi.me/learning-lab-001/

Aqsa Umar’s 28-day independent project explores whether AI-assisted questioning helps her recall and apply what she learns. It includes a daily roadmap, a storyboard journal and the manual ExplainBack prototype.

## Start here

Extract the ZIP and open index.html in a modern browser. Use the same browser and URL each day so your notes stay together. For consistent storage, use the GitHub Pages URL once published, or serve this folder locally with `python -m http.server 8000` and open `http://localhost:8000`. Export your journal before changing URLs or browser profiles.

Day 01 takes 40–55 minutes. Read about retrieval practice, close the source and write 150–200 words without AI. Choose the three linked Hugging Face Unit 1 concepts and rate prior knowledge from 0–2. Day 02 prepares the questions, rubric and README. Run the immediate test on Day 03 and repeat it on Day 05, at least 48 hours later. Day 04 builds the manual prototype, Day 06 drafts a tutorial, and Day 07 checks saving and exporting. The study sessions and prototype may need more than one sitting.

This is a personal learning pilot. Each A/B/C method studies a different concept, so concept difficulty, prior knowledge and order may affect the scores. Report actual results and possible alternative explanations when planning the next test.

The editorial principle is to show real projects being built, including the bugs, in small pieces a beginner can follow. Build notes record the attempt, result, changes, evidence and next step. Optional tutorial fields follow question → source → explanation in my words → small build → test or failure → what I learned → reader exercise. ExplainBack saves and exports these optional fields alongside the original explanation and recall answers. Earlier saved sessions remain readable.

When upgrading at the same URL, related notes from the original first week carry forward and the revised lessons start unchecked. Later lessons retain their progress. The original browser record remains available to the previous version.

The latest content revision retains the existing storage keys and saved day records without resetting completion. Earlier first-week notes therefore stay attached to their original day numbers even though the revised tasks use a different schedule. Review those notes against the new instructions. New tutorial fields are optional.

## Run locally

From this repository directory, run `python -m http.server 8000` and open `http://localhost:8000`. ExplainBack is at `http://localhost:8000/explainback.html`. The site has no dependency installation or build step. Local browser storage belongs to this local address, so notes saved on the published domain will appear when you return to that domain.

## Publish on GitHub Pages

1. Sign in to GitHub and create a public repository named learning-lab-001.
2. Upload the files in this folder to the root of the repository’s main branch. Upload the files, not the enclosing folder or the ZIP.
3. In Settings → Pages, choose Deploy from a branch, then select main and / (root). Save.
4. Open the URL shown in Settings → Pages. Verify Day 01, the incomplete-day dialog and ExplainBack with a fictional session.

The public files contain the curriculum and the prototype. Personal journals and ExplainBack sessions live in local browser storage. The AI exercises use separate public or local tools. No server or API key is required for the website.
